arca-shell — run a command in a working directory with extra env vars injected. Two modes back arca run: a single string arg goes through bash -c (shell syntax, quoting, pipes); multiple argv are exec’d directly — argv[0] is the program, no shell involved. Resolved secrets arrive as (name, exposed-value) pairs and land only in the child’s environment.
