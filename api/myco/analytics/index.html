The analytics emits — format = "timeline"|"stats"|"burnup" (P-012). Same pipeline as every view: the spec’s filter → group → sort → limit resolves first; these formats replace the group render with a purpose-built emit over the filtered universe. Structured --json for pavo/agents, deterministic ASCII on tty.

Universe rules differ per emit:

  • timeline — live top-level items (a roadmap is forward work; archived history has no lanes).
  • stats/burnup — the whole ledger incl. DONE.md and archive/ (the archive is their data), children flattened in — they’re counts, not rows.

source = "index" works identically: snapshots carry items and the archived-id set, so repo/index parity holds for all three emits.
