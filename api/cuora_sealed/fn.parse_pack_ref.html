pub fn parse_pack_ref(arg: &str) -> Result<(String, String), String>
Expand description

Parse cuora://<pack>/<secret> — the sealed-pack ref form. The ref grammar allows deeper paths, but a sealed logical name is a single sealed.files key, so exactly two segments. <pack> may itself be a store spec — bare name, @scope/name, or a name@version/name@<sha> pin (see find_pack).
