arca-ops — the I/O shell every front-end calls.

arca-core is pure domain; this crate is everything that touches the outside world: config loading + env/vault resolution (--env/ARCA_ENV → [envs] routing → a concrete arca_vault::Vault), the env-pin override on refs, the verb operations the CLI calls, and the audit ndjson emission on stderr. arca (CLI) is a thin clap shell over this; arca-tui calls the same functions.
